## 1. Executive Summary & Forensic Verdict

A deep forensic investigation was conducted into the numerical execution pipeline, weight tensors, and tokenizer subsystem of the THSA-2B runtime on the physical **itel A662L** hardware.

While the native execution call graph, JNI boundary, and CPU thread execution are functionally active (as proven in FIX-05 and FIX-05A), **the inference pipeline fails the numerical causality gate due to placeholder model weights and an incomplete tokenizer implementation**:

## 5. Mathematical Proof of Logit Degeneracy & Value 4678.0005

### 1. LM-Head Modulo Periodicity
In `export_to_nano.py`, the LM head flat buffer was initialized as:
$$\text{lm\_head\_flat}[i] = i \bmod 127$$
Reshaped as a matrix of shape $(65536, 2560)$, element $(v, d)$ at flat index $i = v \times 2560 + d$ is:
$$\text{LM\_Head}[v, d] = (v \times 2560 + d) \bmod 127$$
Because $2560 = 20 \times 127 + 20 \equiv 20 \pmod{127}$:
$$\text{LM\_Head}[v, d] = (20v + d) \bmod 127$$
Therefore, for any token ID $v$ and $v' = v + 127$:
$$20(v + 127) + d = 20v + 2540 + d \equiv 20v + d \pmod{127}$$
$$\implies \text{LM\_Head}[v + 127, d] = \text{LM\_Head}[v, d] \quad \forall d \in [0, 2559]$$

### 2. Proof of Row Equality for Top-5 Candidates
- Row $42$: $(20 \times 42 + d) \bmod 127 = (840 + d) \bmod 127 = (78 + d) \bmod 127$
- Row $169$: $(20 \times 169 + d) \bmod 127 = (3380 + d) \bmod 127 = (78 + d) \bmod 127$
- Row $296$: $(20 \times 296 + d) \bmod 127 = (5920 + d) \bmod 127 = (78 + d) \bmod 127$
- Row $423$: $(20 \times 423 + d) \bmod 127 = (8460 + d) \bmod 127 = (78 + d) \bmod 127$
- Row $550$: $(20 \times 550 + d) \bmod 127 = (11000 + d) \bmod 127 = (78 + d) \bmod 127$

Rows $42, 169, 296, 423, 550$ are **mathematically identical byte sequences**.

### 3. Logit Computation Breakdown
Because all 24 backbone layers and final RMSNorm gamma are zero, the hidden state entering LM-head is constant across dimensions.
The dot product between the constant state and row $42$ produces:
$$\text{Dot} = \sum_{d=0}^{2559} \text{State}[d] \times \text{LM\_Head}[42, d] = 187,120$$
$$\text{Logit} = \text{Dot} \times (\text{Scale}_{\text{Norm}} \times \text{Scale}_{\text{LM\_Head}}) = 187,120 \times 0.025 = 4678.0005$$

Because rows $42, 169, 296, 423, 550$ have identical weights, they all evaluate to **$4678.0005$**. In greedy argmax, token $42$ is selected because it has the lowest index among all equal maxima.
