# অধ্যায় ২: মুনাফা (Profit & Interest)

## ২.১ লাভ ও ক্ষতি
ব্যবসায় ক্রয়মূল্য এবং বিক্রয়মূল্যের ওপর লাভ বা ক্ষতি নির্ভর করে।
সূত্র ১: লাভ (Profit) = বিক্রয়মূল্য - ক্রয়মূল্য
সূত্র ২: ক্ষতি (Loss) = ক্রয়মূল্য - বিক্রয়মূল্য
সূত্র ৩: লাভ বা ক্ষতির শতকরা হার সর্বদা ক্রয়মূল্যের ওপর হিসাব করা হয়।
শতকরা লাভ = (মোট লাভ / ক্রয়মূল্য) * ১০০%।

## ২.২ সরল মুনাফা (Simple Interest)
সরল মুনাফা সংক্রান্ত প্রতীকসমূহ:
P = মূলধন বা আসল (Principal)
r = মুনাফার হার (Rate of Interest) = r% = r/১০০
n = সময় (Time in years)
I = সরল মুনাফা (Interest)
A = মুনাফা-আসল বা সবৃদ্ধিমূল (Total Amount)

সূত্র ৪: সরল মুনাফা I = P * r * n
সূত্র ৫: মুনাফা-আসল A = P + I = P + Prn = P(১ + rn)।
সূত্র ৬: আসল নির্ণয় P = I / (r * n) অথবা P = A / (১ + rn)।

উদাহরণ ১: বার্ষিক ১০% মুনাফায় ৩০০০ টাকার ৩ বছরের সরল মুনাফা কত?
সমাধান:
দেওয়া আছে, আসল P = ৩০০০ টাকা, মুনাফার হার r = ১০% = ১০/১০০ = ০.১, সময় n = ৩ বছর।
আমরা জানি, সরল মুনাফা I = P * r * n
I = ৩০০০ * (১০/১০০) * ৩ = ৩০০০ * ০.১ * ৩ = ৯০০ টাকা।
অতএব, মুনাফা ৯০০ টাকা এবং মুনাফা-আসল A = ৩০০০ + ৯০০ = ৩৯০০ টাকা।

## ২.৩ চক্রবৃদ্ধি মুনাফা (Compound Interest)
চক্রবৃদ্ধি মূলধন ও মুনাফা সংক্রান্ত সূত্রাবলী:
C = চক্রবৃদ্ধি মূলধন বা সবৃদ্ধিমূল (Compound Amount)
সূত্র ৭: চক্রবৃদ্ধি মূলধন C = P * (১ + r)^n
সূত্র ৮: চক্রবৃদ্ধি মুনাফা = C - P = P * (১ + r)^n - P = P * {(১ + r)^n - ১}।

উদাহরণ ২: বার্ষিক ৮% চক্রবৃদ্ধি মুনাফায় ৫০০০ টাকার ২ বছরের চক্রবৃদ্ধি মূলধন ও চক্রবৃদ্ধি মুনাফা কত?
সমাধান:
এখানে আসল P = ৫০০০ টাকা, মুনাফার হার r = ৮% = ৮/১০০ = ০.০৮, সময় n = ২ বছর।
চক্রবৃদ্ধি মূলধন C = P * (১ + r)^n
C = ৫০০০ * (১ + ০.০৮)^২ = ৫০০০ * (১.০৮)^২ = ৫০০০ * ১.১৬৬৪ = ৫৮৩২ টাকা।
চক্রবৃদ্ধি মুনাফা = C - P = ৫৮৩২ - ৫০০০ = ৮৩২ টাকা।
