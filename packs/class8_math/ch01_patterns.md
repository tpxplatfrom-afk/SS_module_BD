# অধ্যায় ১: প্যাটার্ন (Patterns)

## ১.১ মৌলিক সংখ্যা ও ইরাটোস্থিনিসের ছাঁকনি
মৌলিক সংখ্যা হলো ১ এর চেয়ে বড় এমন স্বাভাবিক সংখ্যা যার ১ এবং ঐ সংখ্যা ছাড়া অন্য কোনো গুণনীয়ক নেই।
১ থেকে ১০০ পর্যন্ত মৌলিক সংখ্যা মোট ২৫টি।
মৌলিক সংখ্যা চেনার সহজ উপায় হলো ইরাটোস্থিনিসের ছাঁকনি (Sieve of Eratosthenes) পদ্ধতি।
১ কোনো মৌলিক সংখ্যা নয় এবং যৌগিক সংখ্যাও নয়; ১ হলো একটি বিশেষ সংখ্যা।

## ১.২ সংখ্যা প্যাটার্ন ও বীজগাণিতিক রাশি তৈরি
কোনো সংখ্যা তালিকার পাশাপাশি দুটি পদের পার্থক্য যদি সমান থাকে, তবে তাকে সমান্তর প্যাটার্ন বলা হয়।
প্যাটার্নের বীজগাণিতিক রাশি তৈরির নিয়ম:
১. পাশাপাশি দুটি পদের পার্থক্য বের করতে হবে (মনে করি পার্থক্য = d)।
২. বীজগাণিতিক রাশি হবে = (পার্থক্য * k) + স্থির সংখ্যা।
উদাহরণ ১: ৩, ৭, ১১, ১৫, ১৯, ... তালিকার পরবর্তী পদ এবং বীজগাণিতিক রাশি নির্ণয় করো।
সমাধান:
পাশাপাশি দুটি পদের পার্থক্য = ৭ - ৩ = ৪, ১১ - ৭ = ৪।
এখানে পার্থক্য ৪।
১ম পদ = ৪ * ১ - ১ = ৩
২য় পদ = ৪ * ২ - ১ = ৭
অতএব, k-তম পদ বা সাধারণ রাশি = (৪k - ১)।
পরবর্তী পদ = ১৯ + ৪ = ২৩।

## ১.৩ ক্রমিক স্বাভাবিক সংখ্যার যোগফল নির্ণয়
১ম পদ থেকে শুরু করে n সংখ্যক ক্রমিক স্বাভাবিক সংখ্যার যোগফল সূত্র:
সূত্র ১: যোগফল = {(১ম পদ + শেষ পদ) * পদসংখ্যা} / ২
অর্থাৎ, S_n = { (১ম পদ + শেষ পদ) * n } / ২।
উদাহরণ ২: ১ থেকে ৫০ পর্যন্ত ক্রমিক স্বাভাবিক সংখ্যার যোগফল কত?
সমাধান:
এখানে ১ম পদ = ১, শেষ পদ = ৫০, পদসংখ্যা = ৫০।
যোগফল = {(১ + ৫০) * ৫০} / ২ = (৫১ * ৫০) / ২ = ৫১ * ২৫ = ১২৭৫।

## ১.৪ ম্যাজিক বর্গ (Magic Square)
৩ ক্রমের ম্যাজিক বর্গ গঠন:
৩ ক্রমের ম্যাজিক বর্গের ঘরের সংখ্যা = ৩^২ = ৯টি (১ থেকে ৯ পর্যন্ত সংখ্যা)।
ম্যাজিক সংখ্যা নির্ণয়ের সূত্র: ম্যাজিক সংখ্যা = {n * (n^2 + ১)} / ২।
৩ ক্রমের ক্ষেত্রে ম্যাজিক সংখ্যা = {৩ * (৩^২ + ১)} / ২ = {৩ * ১০} / ২ = ১৫।
৪ ক্রমের ক্ষেত্রে ম্যাজিক সংখ্যা = {৪ * (৪^২ + ১)} / ২ = {৪ * ১৭} / ২ = ৩৪।
৩ ক্রমের ম্যাজিক বর্গের মাঝখানের ঘরে সর্বদা ৫ বসে।
