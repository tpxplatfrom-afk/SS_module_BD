# অধ্যায় ৫: বীজগণিতীয় ভগ্নাংশ (Algebraic Fractions)

## ৫.১ ভগ্নাংশের লঘিষ্ঠকরণ ও সাধারণ হরবিশিষ্টকরণ
ভগ্নাংশের লব ও হরকে তাদের সাধারণ গুণনীয়ক বা গ.সা.গু দ্বারা ভাগ করে ক্ষুদ্রতম আকারে প্রকাশ করাকে লঘিষ্ঠকরণ বলে।
সাধারণ হরবিশিষ্ট ভগ্নাংশে রূপান্তরের নিয়ম:
১. প্রদত্ত ভগ্নাংশগুলোর হরসমূহের ল.সা.গু নির্ণয় করতে হবে।
২. হরগুলোর ল.সা.গু-কে প্রত্যেক ভগ্নাংশের হর দিয়ে ভাগ করতে হবে।
৩. প্রাপ্ত ভাগফল দিয়ে সংশ্লিষ্ট ভগ্নাংশের লব ও হর উভয়কে গুণ করতে হবে।

## ৫.২ বীজগণিতীয় ভগ্নাংশের যোগ ও বিয়োগ
ভগ্নাংশের যোগ ও বিয়োগ করার ধাপসমূহ:
১. প্রথমে ভগ্নাংশগুলোর হরগুলোর ল.সা.গু নির্ণয় করতে হবে।
২. ল.সা.গু-কে প্রথম ভগ্নাংশের হর দিয়ে ভাগ করে ভাগফলকে লব দিয়ে গুণ করতে হবে।
৩. একই নিয়মে বাকি ভগ্নাংশগুলোর ক্ষেত্রেও করতে হবে।
৪. প্রাপ্ত পদগুলোকে যোগ বা বিয়োগ চিহ্নের মাধ্যমে একত্রিত করে সরল করতে হবে।

উদাহরণ ১: 1/(x - 2) + 1/(x + 2) এর যোগফল নির্ণয় করো।
সমাধান:
হরদ্বয়ের ল.সা.গু = (x - 2)(x + 2) = x^2 - 4।
যোগফল = { 1*(x + 2) + 1*(x - 2) } / { (x - 2)(x + 2) }
= (x + 2 + x - 2) / (x^2 - 4)
= 2x / (x^2 - 4)।
অতএব, নির্ণেয় যোগফল 2x / (x^2 - 4)।

## ৫.৩ ভগ্নাংশের গুণ, ভাগ ও সরলীকরণ
গুণ করার নিয়ম: লবগুলোর গুণফল হবে নতুন লব এবং হরগুলোর গুণফল হবে নতুন হর।
ভাগ করার নিয়ম: প্রথম ভগ্নাংশ ঠিক রেখে ভাগ চিহ্নের পরিবর্তে গুণ চিহ্ন দিয়ে দ্বিতীয় ভগ্নাংশটিকে উল্টে (বিপরীত ভগ্নাংশ) নিতে হবে।
(a/b) ÷ (c/d) = (a/b) * (d/c) = (ad) / (bc)।
