# অধ্যায় ৮: চতুর্ভুজ ও জ্যামিতিক পরিমাপ (Geometry)

## ৮.১ চতুর্ভুজের মৌলিক ধর্ম ও বৈশিষ্ট্য
চতুর্ভুজ সংক্রান্ত মৌলিক উপপাদ্য ও বৈশিষ্ট্য:
উপপাদ্য ১: চতুর্ভুজের চারটি কোণের সমষ্টি চার সমকোণ বা ৩৬০ ডিগ্রি (৩৬০°)।
উপপাদ্য ২: সামান্তরিকের বিপরীত বাহু ও কোণগুলো পরস্পর সমান।
উপপাদ্য ৩: সামান্তরিকের কর্ণদ্বয় পরস্পরকে সমদ্বিখণ্ডিত করে।
উপপাদ্য ৪: আয়তক্ষেত্রের কর্ণদ্বয় পরস্পর সমান ও পরস্পরকে সমদ্বিখণ্ডিত করে।
উপপাদ্য ৫: রম্বসের কর্ণদ্বয় পরস্পরকে সমকোণে সমদ্বিখণ্ডিত করে।

## ৮.২ পিথাগোরাসের উপপাদ্য ও প্রয়োগ (Pythagoras Theorem)
উপপাদ্য: সমকোণী ত্রিভুজের অতিভুজের ওপর অঙ্কিত বর্গক্ষেত্রের ক্ষেত্রফল অপর দুই বাহুর ওপর অঙ্কিত বর্গক্ষেত্রদ্বয়ের ক্ষেত্রফলের সমষ্টির সমান।
গাণিতিক রূপ: c^2 = a^2 + b^2 অথবা (অতিভুজ)^২ = (লম্ব)^২ + (ভূমি)^২।
প্রয়োজনীয় পিথাগোরিয়ান ত্রয়ী: (৩, ৪, ৫), (৫, ১২, ১৩), (৮, ১৫, ১৭)।

উদাহরণ ১: একটি সমকোণী ত্রিভুজের অতিভুজ ১৩ সেমি এবং ভূমি ৫ সেমি হলে, লম্বের দৈর্ঘ্য কত?
সমাধান:
আমরা জানি, (অতিভুজ)^২ = (লম্ব)^২ + (ভূমি)^২
=> (১৩)^২ = (লম্ব)^২ + (৫)^২
=> ১৬৯ = (লম্ব)^২ + ২৫
=> (লম্ব)^২ = ১৬৯ - ২৫ = ১৪৪
=> লম্ব = √১৪৪ = ১২ সেমি।
অতএব, লম্বের দৈর্ঘ্য ১২ সেমি।

## ৮.৩ বৃত্তের পরিধি ও ক্ষেত্রফল (Circle)
বৃত্ত সংক্রান্ত মৌলিক সূত্রাবলী:
ব্যাসার্ধ = r, ব্যাস d = 2r।
পাই (π) এর আসন্ন মান = ৩.১৪১৬ অথবা ২২/৭।
সূত্র ১: বৃত্তের পরিধি C = 2 * π * r
সূত্র ২: বৃত্তের ক্ষেত্রফল A = π * r^2
উদাহরণ ২: একটি বৃত্তের ব্যাসার্ধ ৭ সেমি হলে এর পরিধি ও ক্ষেত্রফল কত? (π = ২২/৭)
সমাধান:
পরিধি C = 2 * (২২/৭) * ৭ = ৪৪ সেমি।
ক্ষেত্রফল A = (২২/৭) * (৭)^২ = (২২/৭) * ৪৯ = ২২ * ৭ = ১৫৪ বর্গসেমি।
