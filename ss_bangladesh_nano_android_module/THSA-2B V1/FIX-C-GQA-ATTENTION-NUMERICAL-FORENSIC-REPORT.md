## 4. MATHEMATICAL SPECIFICATION & ALGORITHMS

### Model Hyperparameters
- $d_{\text{model}} = 2560$
- $d_{\text{head}} = 128$
- $n_q = 20$ Query heads ($20 \times 128 = 2560$)
- $n_{kv} = 4$ Key/Value heads ($4 \times 128 = 512$)
- GQA Group Ratio: $5:1$ ($\frac{n_q}{n_{kv}} = \frac{20}{4} = 5$)
- Attention scale: $\sigma = \frac{1}{\sqrt{d_{\text{head}}}} = \frac{1}{\sqrt{128}} \approx 0.0883883476$
- GQA Layers: $2, 5, 8, 11, 14, 17, 20, 23$

### PyTorch GQA Algorithm (Authoritative Ground Truth)
```python
x_n = rms_norm(x, norm_w)
q = (x_n @ W_q.T).view(1, S, 20, 128).transpose(1, 2)    # [1, 20, S, 128]
k = (x_n @ W_k.T).view(1, S, 4, 128).transpose(1, 2)     # [1, 4, S, 128]
v = (x_n @ W_v.T).view(1, S, 4, 128).transpose(1, 2)     # [1, 4, S, 128]

k_exp = k.repeat_interleave(5, dim=1)                    # [1, 20, S, 128]
v_exp = v.repeat_interleave(5, dim=1)                    # [1, 20, S, 128]

scores = torch.matmul(q, k_exp.transpose(-1, -2)) * (1.0 / math.sqrt(128))
causal_mask = torch.triu(torch.full((S, S), -inf), diagonal=1)
scores = scores + causal_mask
attn_w = F.softmax(scores, dim=-1)
context = torch.matmul(attn_w, v_exp).transpose(1, 2).contiguous().view(1, S, 2560)
out = context @ W_out.T
```

### Reference-B Algorithm Defect (Forensically Proven)
In `tools/fix12c_phase_d_reference_b_hidden.py` (lines 325-331), Reference-B had a hardcoded sequence-1 shortcut:
```python
# GQA Multi-head sequence-1 attention:
repeat_factor = NQ // NKV  # 5
v_exp = v.reshape(NKV, DH).repeat(repeat_factor, axis=0).reshape(-1)
```
Reference-B discarded previous KV cache tokens and dumped $V_3$ (expanded to 20 heads) as the attention output. Comparing $V_3$ against the true multi-token attention output generated by Android Native produced the apparent divergence (cosine 0.4242).

### Native C++ Algorithm
1. **Q/K/V Projections:**
   - $Q \in \mathbb{R}^{2560}$ via ternary GEMV (`lp.w_q_packed`)
   - $K \in \mathbb{R}^{512}$ via ternary GEMV (`lp.w_k_packed`)
   - $V \in \mathbb{R}^{512}$ via ternary GEMV (`lp.w_v_packed`)
2. **KV Cache Persistence:**
   - Each KV head $h \in \{0, 1, 2, 3\}$ of dimension 128 is quantized into INT4 representation (64 bytes) with dynamic symmetric scaling:
     $$\text{scale} = \frac{\max(|x|)}{7.0}, \quad q = \text{clip}\left(\left\lfloor \frac{x}{\text{scale}} + 0.5 \right\rfloor + 7, 0, 15\right)$$
   - Written at offset $(h \cdot 10000 + t) \cdot 64$.
3. **Causal Attention Assembly:**
   - For query head $q\_h \in \{0..19\}$, KV head index is $kv\_h = \lfloor q\_h / 5 \rfloor$.
   - For past tokens $t \in \{0..\text{seq\_len}-1\}$, Key is dequantized and dotted:
     $$\text{dot} = \sum_{d=0}^{127} Q[q\_h, d] \cdot K[kv\_h, t, d], \quad \text{score}[t] = \text{dot} \cdot \frac{1}{\sqrt{128}}$$
   - Stable softmax with max subtraction:
     $$w[t] = \frac{\exp(\text{score}[t] - \max(s))}{\sum_{\tau} \exp(\text{score}[\tau] - \max(s))}$$
   - Value accumulation:
     $$\text{out\_head}[q\_h, d] = \sum_{t=0}^{\text{seq\_len}-1} w[t] \cdot V[kv\_h, t, d]$$
4. **Out-Projection & Residual:**
   - Quantized to INT8 and projected through `w_out_packed` [2560, 2560], then added to residual.
