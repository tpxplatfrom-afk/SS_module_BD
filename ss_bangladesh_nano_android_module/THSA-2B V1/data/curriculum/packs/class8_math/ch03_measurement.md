# অধ্যায় ৩: পরিমাপ (Measurement)

## ৩.১ ক্ষেত্রফল পরিমাপ সংক্রান্ত সূত্রাবলী
আয়তক্ষেত্র ও বর্গক্ষেত্রের পরিমাপ:
সূত্র ১: আয়তক্ষেত্রের ক্ষেত্রফল = দৈর্ঘ্য * প্রস্থ
সূত্র ২: আয়তক্ষেত্রের পরিসীমা = ২ * (দৈর্ঘ্য + প্রস্থ)
সূত্র ৩: বর্গক্ষেত্রের ক্ষেত্রফল = (এক বাহুর দৈর্ঘ্য)^২
সূত্র ৪: বর্গক্ষেত্রের পরিসীমা = ৪ * এক বাহুর দৈর্ঘ্য
সূত্র ৫: ত্রিভুজের ক্ষেত্রফল = ১/২ * ভূমি * উচ্চতা

উদাহরণ ১: একটি আয়তাকার বাগানের দৈর্ঘ্য ৬০ মিটার এবং প্রস্থ ৪০ মিটার। এর ক্ষেত্রফল ও পরিসীমা নির্ণয় করো।
সমাধান:
আয়তাকার বাগানের ক্ষেত্রফল = দৈর্ঘ্য * প্রস্থ = ৬০ * ৪০ = ২৪০০ বর্গমিটার।
পরিসীমা = ২ * (দৈর্ঘ্য + প্রস্থ) = ২ * (৬০ + ৪০) = ২ * ১০০ = ২০০ মিটার।

## ৩.২ আয়তাকার বাগানের চতুর্দিকের রাস্তার ক্ষেত্রফল
রাস্তা যদি বাগানের বাইরে থাকে:
১. রাস্তাসহ বাগানের দৈর্ঘ্য = মূল দৈর্ঘ্য + ২ * (রাস্তার বিস্তার)
২. রাস্তাসহ বাগানের প্রস্থ = মূল প্রস্থ + ২ * (রাস্তার বিস্তার)
৩. রাস্তাসহ মোট ক্ষেত্রফল = রাস্তাসহ দৈর্ঘ্য * রাস্তাসহ প্রস্থ
৪. রাস্তার ক্ষেত্রফল = রাস্তাসহ ক্ষেত্রফল - মূল বাগানের ক্ষেত্রফল।

## ৩.৩ তরল ও ঘনবস্তুর আয়তন ও একক রূপান্তর
তরল পদার্থের আয়তন লিটার এককে মাপা হয়।
সূত্র ৬: ঘনবস্তুর আয়তন = দৈর্ঘ্য * প্রস্থ * উচ্চতা
প্রয়োজনীয় একক রূপান্তর:
- ১ মিটার = ১০০ সেন্টিমিটার = ৩৯.৩৭ ইঞ্চি (প্রায়)
- ১ ইঞ্চি = ২.৫৪ সেন্টিমিটার (প্রায়)
- ১ গজ = ০.৯১৪৪ মিটার = ৩৬ ইঞ্চি
- ১ মাইল = ১.৬১ কিলোমিটার (প্রায়)
- ১ লিটার বিশুদ্ধ পানির ওজন = ১ কিলোগ্রাম (১ কেজি)
- ১ ঘনমিটার = ১০০০ লিটার
- ১ একর = ৪৮৪০ বর্গগজ = ৪০৪৬.৮৬ বর্গমিটার (প্রায়)
- ১ হেক্টর = ১০০ এয়র = ১০০০০ বর্গমিটার = ২.৪৭ একর (প্রায়)।
