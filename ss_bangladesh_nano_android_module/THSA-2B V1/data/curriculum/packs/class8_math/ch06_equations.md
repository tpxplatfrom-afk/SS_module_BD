# অধ্যায় ৬: সরল সহসমীকরণ (Linear Simultaneous Equations)

## ৬.১ প্রতিস্থাপন পদ্ধতি (Substitution Method)
দুই চলকবিশিষ্ট দুটি সরল সহসমীকরণকে প্রতিস্থাপন পদ্ধতিতে সমাধানের ধাপসমূহ:
ধাপ ১: যেকোনো একটি সমীকরণ থেকে একটি চলকের মান অপর চলকের মাধ্যমে প্রকাশ করতে হবে (যেমন x = f(y))।
ধাপ ২: এই প্রাপ্ত মানটি অপর সমীকরণে বসিয়ে এক চলকবিশিষ্ট সমীকরণে রূপান্তর করে সেই চলকটির মান বের করতে হবে।
ধাপ ৩: প্রাপ্ত মানটি সুবিধাজনক যেকোনো সমীকরণে বসিয়ে অন্য চলকটির মান নির্ণয় করতে হবে।

উদাহরণ ১: প্রতিস্থাপন পদ্ধতিতে সমাধান করো:
x + y = 7 ... (১)
x - y = 3 ... (২)
সমাধান:
সমীকরণ (২) হতে পাই, x = y + 3 ... (৩)
সমীকরণ (১) এ x এর মান বসিয়ে পাই,
(y + 3) + y = 7
=> 2y + 3 = 7
=> 2y = 7 - 3 = 4
=> y = 4 / 2 = 2।
এখন সমীকরণ (৩) এ y = 2 বসিয়ে পাই, x = 2 + 3 = 5।
অতএব, নির্ণেয় সমাধান (x, y) = (5, 2)।

## ৬.২ অপনয়ন পদ্ধতি (Elimination Method)
অপনয়ন পদ্ধতিতে সমাধানের ধাপসমূহ:
ধাপ ১: সুবিধাজনক সংখ্যা দিয়ে সমীকরণ দুটিকে এমনভাবে গুণ করতে হবে যেন যেকোনো একটি চলকের সহগের পরম মান সমান হয়।
ধাপ ২: চলকটির সহগগুলোর চিহ্ন বিপরীত (+ ও -) হলে সমীকরণ দুটি যোগ এবং একই চিহ্ন হলে বিয়োগ করে একটি চলক অপনীত করতে হবে।
ধাপ ৩: এক চলকবিশিষ্ট সরল সমীকরণ সমাধান করে মান বের করতে হবে এবং অপর চলকের মান বের করতে তা যেকোনো মূল সমীকরণে বসাতে হবে।

উদাহরণ ২: অপনয়ন পদ্ধতিতে সমাধান করো:
2x + 3y = 13 ... (১)
x + y = 5 ... (২)
সমাধান:
সমীকরণ (২) কে ২ দিয়ে গুণ করে সমীকরণ (১) থেকে বিয়োগ করি:
  2x + 3y = 13
- 2x + 2y = 10
---------------
          y = 3
সমীকরণ (২) এ y = 3 বসিয়ে পাই, x + 3 = 5 => x = 5 - 3 = 2।
অতএব, নির্ণেয় সমাধান (x, y) = (2, 3)।
