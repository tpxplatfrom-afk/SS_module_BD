# ৯ম-১০ম শ্রেণি উচ্চতর গণিত (Higher Mathematics) — পূর্ণাঙ্গ হ্যান্ডবুক

## অধ্যায় ১০: দ্বিপদী বিস্তৃতি (Binomial Expansion)
- প্যাসকেলের ত্রিভুজ সূত্র (Pascal's Triangle): প্রতিটি পদের সহগ উপরের সারির পাশাপাশি দুটি পদের যোগফলের সমান।
- দ্বিপদী উপপাদ্য (Binomial Theorem):
  * (1 + y)^n = 1 + ny + {n(n-1)/2!} y² + {n(n-1)(n-2)/3!} y³ + ... + y^n
  * (a + b)^n = nC0 a^n + nC1 a^(n-1)b + nC2 a^(n-2)b² + ... + nCn b^n
- সাধারণ পদ (General Term): T_(r+1) = nCr a^(n-r) b^r
- সমাবেশ সূত্র (Combination): nCr = n! / {r! (n - r)!}

## অধ্যায় ১১: স্থানাঙ্ক জ্যামিতি (Coordinate Geometry)
- দুটি বিন্দু P(x1, y1) এবং Q(x2, y2) এর মধ্যবর্তী দূরত্ব:
  * d = √[(x2 - x1)² + (y2 - y1)²]
- সরলরেখার ঢাল (Slope, m):
  * m = (y2 - y1) / (x2 - x1) = tan θ
- সমীকরণ আকার: y = mx + c (যেখানে m = ঢাল, c = y-অক্ষের ছেদাংশ)।
- ত্রিভুজ ক্ষেত্রফল: A = (1/2) | x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2) |

## অধ্যায় ১৪: সম্ভাবনা (Probability)
- সম্ভাবনা সূত্র: P(A) = (অনুকূল ফলাফল সংখ্যা) / (সমগ্র সম্ভাব্য ফলাফল সংখ্যা)
- শর্তাবলী: 0 <= P(A) <= 1
- নিশ্চিত ঘটনার সম্ভাবনা = ১, অসম্ভব ঘটনার সম্ভাবনা = ০।
- পরিপূরক ঘটনা: P(A') = 1 - P(A)।
- প্রোবাবিলিটি ট্রি (Probability Tree) অঙ্কন পদ্ধতি।
