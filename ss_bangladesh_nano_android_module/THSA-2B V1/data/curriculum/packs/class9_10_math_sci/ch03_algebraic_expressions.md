# ৯ম-১০ম শ্রেণি গণিত — ৩য় অধ্যায়: বীজগাণিতিক রাশি (Algebraic Expressions)
## ৩.১ বর্গের সূত্রাবলী ও অনুসিদ্ধান্ত
- সূত্র ১: (a + b)² = a² + 2ab + b²
- সূত্র ২: (a - b)² = a² - 2ab + b²
- সূত্র ৩: a² - b² = (a + b)(a - b)
- অনুসিদ্ধান্ত ১: a² + b² = (a + b)² - 2ab = (a - b)² + 2ab
- অনুসিদ্ধান্ত ২: (a + b)² = (a - b)² + 4ab
- অনুসিদ্ধান্ত ৩: (a - b)² = (a + b)² - 4ab
- অনুসিদ্ধান্ত ৪: 2(a² + b²) = (a + b)² + (a - b)²
- অনুসিদ্ধান্ত ৫: 4ab = (a + b)² - (a - b)² বা ab = {(a+b)/2}² - {(a-b)/2}²

## ৩.২ ঘনের সূত্রাবলী
- (a + b)³ = a³ + 3a²b + 3ab² + b³ = a³ + b³ + 3ab(a + b)
- (a - b)³ = a³ - 3a²b + 3ab² - b³ = a³ - b³ - 3ab(a - b)
- a³ + b³ = (a + b)(a² - ab + b²) = (a + b)³ - 3ab(a + b)
- a³ - b³ = (a - b)(a² + ab + b²) = (a - b)³ + 3ab(a - b)
