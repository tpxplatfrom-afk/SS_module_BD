# ৯ম-১০ম শ্রেণি গণিত — ৪র্থ অধ্যায়: সূচক ও লগারিদম (Exponents & Logarithms)
## ৪.১ সূচকের সূত্রাবলী
- a^m × a^n = a^(m+n)
- a^m / a^n = a^(m-n)
- (a^m)^n = a^(mn)
- (ab)^n = a^n × b^n
- a^0 = 1 (যেখানে a != 0)
- a^(-n) = 1 / a^n
- n√a = a^(1/n)

## ৪.২ লগারিদমের সূত্রাবলী
- log_a(1) = 0, log_a(a) = 1
- log_a(M × N) = log_a(M) + log_a(N)
- log_a(M / N) = log_a(M) - log_a(N)
- log_a(M^k) = k × log_a(M)
- ভিত্তি পরিবর্তন: log_a(M) = log_b(M) × log_a(b)
