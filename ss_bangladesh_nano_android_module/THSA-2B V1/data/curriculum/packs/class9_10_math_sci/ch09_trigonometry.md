# ৯ম-১০ম শ্রেণি গণিত — ৯ম অধ্যায়: ত্রিকোণমিতিক অনুপাত (Trigonometry)
## ৯.১ ত্রিকোণমিতিক অনুপাতের সংজ্ঞা
- সমকোণী ত্রিভুজে:
  * sin θ = লম্ব / অতিভুজ
  * cos θ = ভূমি / অতিভুজ
  * tan θ = লম্ব / ভূমি = sin θ / cos θ
  * cosec θ = ১ / sin θ = অতিভুজ / লম্ব
  * sec θ = ১ / cos θ = অতিভুজ / ভূমি
  * cot θ = ১ / tan θ = ভূমি / লম্ব

## ৯.২ মৌলিক ত্রিকোণমিতিক অভেদাবলী
- sin² θ + cos² θ = 1  =>  sin² θ = 1 - cos² θ, cos² θ = 1 - sin² θ
- sec² θ - tan² θ = 1  =>  sec² θ = 1 + tan² θ, tan² θ = sec² θ - 1
- cosec² θ - cot² θ = 1 => cosec² θ = 1 + cot² θ, cot² θ = cosec² θ - 1

## ৯.৩ আদর্শ কোণসমূহের মান (0°, 30°, 45°, 60°, 90°)
- sin 0° = 0, sin 30° = 1/2, sin 45° = 1/√2, sin 60° = √3/2, sin 90° = 1
- cos 0° = 1, cos 30° = √3/2, cos 45° = 1/√2, cos 60° = 1/2, cos 90° = 0
- tan 0° = 0, tan 30° = 1/√3, tan 45° = 1, tan 60° = √3, tan 90° = অসংজ্ঞায়িত
