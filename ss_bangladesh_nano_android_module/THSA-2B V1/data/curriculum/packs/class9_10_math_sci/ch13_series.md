# ৯ম-১০ম শ্রেণি গণিত — ১৩শ অধ্যায়: সসীম ধারা (Finite Series)
## ১৩.১ সমান্তর ধারা (Arithmetic Progression)
- ১ম পদ a এবং সাধারণ অন্তর d হলে:
  * n-তম পদ = a + (n - 1)d
  * প্রথম n সংখ্যক পদের সমষ্টি S_n = (n/2) × {2a + (n - 1)d}
  * ১ম n সংখ্যক স্বাভাবিক সংখ্যার সমষ্টি: 1 + 2 + 3 + ... + n = {n(n + 1)} / 2
  * ১ম n সংখ্যক স্বাভাবিক সংখ্যার বর্গের সমষ্টি: 1² + 2² + ... + n² = {n(n + 1)(2n + 1)} / 6
  * ১ম n সংখ্যক স্বাভাবিক সংখ্যার ঘনের সমষ্টি: 1³ + 2³ + ... + n³ = [{n(n + 1)} / 2]²

## ১৩.২ গুণোত্তর ধারা (Geometric Progression)
- ১ম পদ a এবং সাধারণ অনুপাত r হলে:
  * n-তম পদ = a × r^(n - 1)
  * সমষ্টি S_n = a(1 - r^n) / (1 - r) যখন r < 1
  * সমষ্টি S_n = a(r^n - 1) / (r - 1) যখন r > 1
